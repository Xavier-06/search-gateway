# 搜索引擎路由规则

## 路由策略

系统根据查询内容自动选择最优搜索引擎：

```
┌─────────────────────────────────────────┐
│           用户查询                        │
└───────────────┬─────────────────────────┘
                 │
                 ▼
        ┌────────────────┐
        │ 含中文字符？     │
        └───────┬────────┘
                │
         ┌──────┴──────┐
         │YES          │NO
         ▼             ▼
    ┌─────────┐  ┌─────────────────┐
    │DDG CLI  │  │ 含股票代码？      │
    │(中文最优)│  └────────┬────────┘
    └─────────┘           │
                   ┌──────┴──────┐
                   │YES          │NO
                   ▼             ▼
              ┌─────────┐  ┌───────────┐
              │DDG CLI  │  │ SearXNG   │
              │         │  │ (英文最优) │
              └─────────┘  └───────────┘
```

## 引擎特性

### DuckDuckGo (DDG)

| 特性 | 说明 |
|------|------|
| 中文搜索 | ✅ 最优，零配置 |
| 英文搜索 | ✅ 优秀 |
| 代理需求 | ❌ 不需要 |
| API 限制 | 宽松 |

**适用场景：**
- 中文查询
- 股票代码搜索
- 混合语言查询
- 国内用户首选

### SearXNG

| 特性 | 说明 |
|------|------|
| 中文搜索 | ⚠️ 需要配置中文引擎 |
| 英文搜索 | ✅ 优秀 |
| 多引擎聚合 | ✅ Google/Bing/Baidu |
| 代理需求 | ⚠️ 国内需要 |

**适用场景：**
- 英文深度搜索
- 需要多引擎结果聚合
- 海外用户首选

### Google Direct

| 特性 | 说明 |
|------|------|
| 中文搜索 | ✅ 优秀 |
| 英文搜索 | ✅ 最优 |
| 代理需求 | ✅ 必需 |
| 反爬强度 | 高 |

**适用场景：**
- 需要 Google 专属结果
- 有稳定代理可用

## 降级策略

```
DDG ──失败──→ SearXNG ──失败──→ Google Direct
  │              │                │
  │              │                └── 需要代理
  │              └── 国内可能需要代理
  └── 完全不需要代理
```

## 深度抓取路由

页面正文抓取时，根据域名判断代理需求：

```python
# 国内站点 → 直连（无需代理）
CN_DOMAINS = [".cn", "baidu.com", "zhihu.com", "163.com", "qq.com", "sina.com"]

# 海外站点 → 使用代理
need_proxy = not any(d in url for d in CN_DOMAINS)
```
